## Claim (route, not the theorem)

Lamé’s route needs: for every odd prime \(p\) appearing as an FLT exponent,
\(\mathbb{Z}[\zeta_p]\) is a UFD (so the cyclotomic factors \(x + \zeta^j y\)
behave like prime elements). FLT itself is true; the **route** dies wherever
that UFD hypothesis is false.

## Load-bearing false premise

1. Factor \(x^p + y^p = \prod_{j=0}^{p-1}(x + \zeta_p^j y)\) in \(\mathbb{Z}[\zeta_p]\).
2. Argue the factors are pairwise coprime (under FLT coprimality hypotheses).
3. Invoke **unique factorization into primes/irreducibles** to conclude each
   factor is a \(p\)-th power (up to units) → infinite descent.
4. **Break:** step 3 requires \(\mathbb{Z}[\zeta_p]\) to be a UFD / PID. That
   fails as soon as the class number \(h_p > 1\).

**Gate value for the first failure:** \(p = 23\), \(h_{23} = 3\).

## What this milestone gates (Python)

Exact-integer checks only (laptop stack; no Sage/Magma):

1. **Relative class number \(h^-_p\)** via the Maillet / OEIS determinant formula
   (Alekseyev / OEIS A000927): for odd prime \(p \ge 5\),
   \[
   h^-_p = \Bigl|\det\bigl(M\bigr)\Bigr|,
   \]
   where \(M\) is the \(((p-3)/2)\times((p-3)/2)\) integer matrix with
   \[
   M_{i,j} = \Bigl\lfloor\frac{(i+1)(j+2)}{p}\Bigr\rfloor
            - \Bigl\lfloor\frac{i(j+2)}{p}\Bigr\rfloor
   \]
   (1-based \(i,j\) as in the OEIS Maple/PARI programs).  
   **Expect:** \(h^-_{23} = 3\), and \(h^-_p = 1\) for all primes \(p < 23\).

2. **OEIS pin:** A000927 terms through \(p=47\) match the determinant
   (sanity that the formula implementation is the published one).

3. **Quadratic witness:** class number of \(\mathbb{Q}(\sqrt{-23})\) equals \(3\)
   by enumerating reduced positive-definite binary quadratic forms of
   discriminant \(-23\):
   \[
   (a,b,c) \in \{(1,1,6),\ (2,-1,3),\ (2,1,3)\}.
   \]
   (Classical: the Hilbert class field of \(\mathbb{Q}(\sqrt{-23})\) sits inside
   \(\mathbb{Q}(\zeta_{23})\); this is a supporting finite certificate, not a
   substitute for \(h_{23}\) itself.)

4. **Plus part:** \(h^+_{23} = 1\) is classical for this conductor (Washington /
   van der Linden tables; OEIS A055513 notes \(h = h^- h^+\) agrees with \(h^-\)
   for the first many primes). Hence \(h_{23} = h^-_{23}\, h^+_{23} = 3\).

**PASS** = all of (1)–(3) hold with \(h^-_{23}=3\) and first failure at \(23\).  
**BREAK** = determinant disagrees with OEIS, or \(h^-_{23}\neq 3\), or form count
\(\neq 3\).
