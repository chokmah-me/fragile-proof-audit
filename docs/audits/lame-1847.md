## What was gated

- Maillet / OEIS A000927 determinant for \(h^-_p\) on primes through \(47\):
  matches OEIS prefix exactly; \(h^-_{23} = 3\).
- First odd prime with \(h^- > 1\) is \(23\) (all smaller odd primes in the pin
  have \(h^- = 1\)).
- Reduced forms of discriminant \(-23\): \((1,1,6)\), \((2,-1,3)\),
  \((2,1,3)\) → class number \(3\).
- Cited (not recomputed): \(h^+_{23} = 1\) ⇒ \(h_{23} = 3\).

## Regular vs UFD (do not confuse)

\(23 \nmid 3\), so \(23\) is **Kummer-regular**. Lamé’s break is still real:
UFD requires class number \(1\), not merely \(p \nmid h\). Kummer’s salvage for
regular primes uses ideal factorization, which Lamé did not have.
